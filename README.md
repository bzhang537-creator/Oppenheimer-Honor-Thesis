# Oppenheimer Honors Thesis — `v1-crossref` (archived)

**Archived history. No longer maintained.** This was the first version of the project, built on
publication data pulled from the **Crossref** API. It established the basic research question — whether
the political shocks to Oppenheimer (1942 Manhattan Project, 1949 Soviet test, 1954 clearance
revocation) suppressed the productivity of physicists in his co-authorship network — and the initial
exposure-tier structure (E1 direct co-authors, E2 co-authors of co-authors, E3 IAS physicists).

Crossref coverage of pre-1960 *Physical Review* proved incomplete and inconsistent, so this branch was
retired in favor of data collected directly from the APS Physical Review Online Archive (PROLA). It is
kept only as a record of the project's starting point.

**Current work lives on [`v3-unified-event-study`](https://github.com/bzhang537-creator/Oppenheimer-Honor-Thesis/tree/v3-unified-event-study); see the [`main`](https://github.com/bzhang537-creator/Oppenheimer-Honor-Thesis) branch for the project overview.**
